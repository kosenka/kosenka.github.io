# proxy

1. Откройте Telegram → нажмите на три полоски (меню) → Настройки

2. Выберите Данные и память → в самый низ → Настройки прокси

3. Нажмите "Добавить прокси"

4. Выберите тип "MTProto"

5. Введи данные: Сервер (IP/хост) и Порт и секретный ключ для MTProto (список прокси серверов смотрите ниже)

6. Нажмите галочку (сохранить). Статус изменится на "Подключено"
