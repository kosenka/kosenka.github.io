# proxy

1.Откройте Telegram → нажми на три полоски (меню) → Настройки

2.Выбери Данные и память → в самый низ → Настройки прокси

3.Нажми Добавить прокси

4.Выбери тип MTProto

5.Введи данные: Сервер (IP/хост) и Порт и секретный ключ для MTProto

6.Нажми галочку (сохранить). Статус изменится на "Подключено"
